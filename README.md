# Sing-Box VPN Tray Manager

Приложение для управления VPN клиентом sing-box через системный трей Windows.

## Возможности

- **Системный трей** с иконкой "4R" на оранжевом фоне
- **Управление VPN**: включение и выключение одним кликом
- **Индикатор состояния**: текстовая индикация в меню (Запущен/Остановлен)
- **Импорт серверов из буфера обмена**: ссылки vless://, vmess://, trojan://, ss://, hysteria2:// (hy2://), а также base64-подписки с несколькими серверами
- **Импорт серверов по QR-коду**: сканирование QR-кода прямо с экрана (все мониторы)
- **Настройки в браузере**: редактирование блоков `outbounds` и `route` как JSON, выбор активного сервера одной кнопкой, импорт; перед сохранением конфиг проверяется через `sing-box check`
- **Обновление sing-box**: проверка и установка последнего релиза с официального GitHub (SagerNet/sing-box) со сверкой с текущей версией
- **Обход DPI (zapret в Docker)**: запуск инструмента обхода DPI в Docker-контейнере и подключение его в конфиг по необходимости — цепочкой через активный сервер или как отдельный outbound
- **Автозапуск**: управление автозапуском через меню с галочкой
- **Сохранение состояния**: запоминает последнее состояние VPN (включен/выключен) и восстанавливает его при запуске
- **Права администратора**: автоматический запрос прав администратора

## Требования

- Windows 7 или выше
- Go 1.24 или выше (для сборки)
- sing-box.exe
- config.json (конфигурация sing-box)

## Сборка

1. Установите зависимости:
```bash
go mod download
```

2. Соберите (из WSL, использует Windows-тулчейн Go через interop):
```bash
make
```

Или вручную:

```bash
# Сгенерировать иконку из SVG
go run ./tools/genicons

# Собрать приложение
go build -ldflags="-H windowsgui" -o bin/tray-sing-box.exe .

# Вшить ресурсы Windows в exe (иконка, манифест с правами администратора, версия)
go-winres patch --in build/winres/winres.json --no-backup bin/tray-sing-box.exe
```

## Установка

1. Соберите приложение (см. выше)
2. Поместите `sing-box.exe` и `config.json` в папку `bin` рядом с `tray-sing-box.exe`
3. Запустите `bin/tray-sing-box.exe` (потребуются права администратора)

## Использование

После запуска приложение появится в системном трее с иконкой "4R" на оранжевом фоне.

### Меню содержит:

1. **Статус** - показывает текущее состояние VPN
   - ● Остановлен - VPN выключен
   - ● Запущен - VPN включен

2. **Включить/Выключить** - переключение состояния VPN

3. **Импорт из буфера обмена** - импорт сервера(ов) из ссылки или base64-подписки в буфере обмена

4. **Импорт QR с экрана** - поиск QR-кода с ссылкой на сервер на экране и его импорт

5. **Настройки** - открывает веб-интерфейс настроек в браузере

6. **Обновить sing-box** - проверяет последний релиз на GitHub и обновляет sing-box.exe, если он новее установленного

7. **Обход DPI (zapret)** - галочка: поднимает zapret в Docker и заворачивает подключение активного сервера через него (обход DPI на самом VPN-подключении)
   - ✓ Галочка означает, что цепочка через zapret включена
   - Работает только с TCP-серверами (vless/trojan/vmess); для hysteria2/tuic (UDP) недоступно
   - Требуется запущенный Docker Desktop

8. **Автозапуск** - управление автозапуском при старте Windows
   - ✓ Галочка означает, что автозапуск включен
   - Нажмите для включения/выключения автозапуска

9. **Выход** - закрытие приложения (VPN продолжает работать в фоне, состояние сохраняется)

### Обновление sing-box:

- Текущая версия определяется через `sing-box version`, последняя — через GitHub API (релизы SagerNet/sing-box)
- Обновление выполняется только если релиз новее установленной версии (даунгрейда нет)
- Скачивается zip под архитектуру системы, бинарник проверяется запуском до установки
- Старый бинарник сохраняется как `sing-box.exe.old` и восстанавливается при сбое
- Если VPN был запущен — он останавливается только на время замены файла и запускается снова

### Обход DPI (zapret в Docker):

- Инструмент zapret запускается в Docker-контейнере (`8hrsk/zapret-docker-proxy`, режим `--privileged`) и публикует HTTP-прокси на `127.0.0.1:3128`; десинхронизацию DPI делает nfqws на исходящем трафике контейнера
- **Цепочка (режим A)** — галочка «Обход DPI» в трее или кнопка в веб-интерфейсе: к активному прокси-серверу добавляется `detour` на `dpi-bypass`, и подключение к VPN-серверу идёт через zapret. Подходит, когда провайдер блокирует сам VPN-сервер по DPI
  - Только для TCP-серверов (`vless`/`trojan`/`vmess`): HTTP-прокси не пропускает UDP, поэтому для `hysteria2`/`tuic` режим отклоняется с понятным сообщением
- **Прямой обход (режим B)** — в веб-интерфейсе кнопка «Подготовить прямой обход», затем выберите `dpi-bypass` в списке серверов: трафик идёт через zapret без VPN/шифрования
- Требуется установленный и запущенный Docker Desktop; иначе обе точки входа показывают «Docker не найден или не запущен…», а трей продолжает работать без зависаний
- Контейнер стартует до правки конфига; при выключении цепочки контейнер останавливается, если прямой обход его не использует
- Параметры стратегии nfqws (под конкретного провайдера) можно задать в файле `dpi-params.txt` рядом с `tray-sing-box.exe` — он передаётся как `ZAPRET_PARAMS` при создании контейнера (смена требует пересоздания контейнера)

### Настройки (веб-интерфейс):

- **Активный сервер** — список всех outbounds; выберите сервер и нажмите «Использовать выбранный»: все правила маршрутизации, указывающие на прокси (и `route.final`, если он указывал на прокси), переключаются на выбранный сервер
- **Импорт** — кнопки импорта из буфера обмена и QR с экрана
- **Outbounds / Route (JSON)** — редактирование секций конфига текстом; перед сохранением проверяется корректность JSON и, если sing-box.exe рядом, конфиг прогоняется через `sing-box check`
- Любое изменение автоматически перезапускает VPN, если он запущен
- Интерфейс доступен только с этого компьютера (127.0.0.1) и защищён одноразовым токеном

### Импорт серверов:

- Поддерживаемые ссылки: `vless://`, `vmess://`, `trojan://`, `ss://` (SIP002 и legacy), `hysteria2://`, `hy2://`
- Если в тексте несколько ссылок или это base64-подписка — импортируются все серверы сразу
- Outbound добавляется в `config.json` (сервер с тем же тегом заменяется), тег регистрируется во всех группах selector/urltest
- Перед изменением создаётся резервная копия `config.json.bak`
- Если VPN запущен — он автоматически перезапускается с новым конфигом
- Результат импорта показывается во всплывающем окне

### Сохранение состояния VPN:

- **VPN работает независимо от приложения трея**: sing-box.exe продолжает работать даже после закрытия приложения
- При включении/выключении VPN состояние сохраняется в реестре Windows
- При следующем запуске (в том числе при автозапуске) приложение автоматически восстанавливает последнее состояние:
  - Если VPN был включен - подключается к уже работающему процессу sing-box или запускает новый
  - Если VPN был выключен - не запускает sing-box
- При закрытии приложения через меню "Выход" VPN продолжает работать, что позволяет сохранить интернет-соединение

## Технические детали

- **Язык**: Go
- **Библиотека трея**: github.com/getlantern/systray
- **Работа с реестром**: golang.org/x/sys/windows/registry
- **Запуск sing-box**: `sing-box.exe run -c config.json`

## Примечания

- Приложение автоматически запрашивает права администратора при запуске
- Консольное окно sing-box скрывается при запуске
- **При закрытии приложения VPN продолжает работать в фоновом режиме**
- Для полной остановки VPN сначала выключите его через меню, затем закройте приложение
- **Логирование**: все события записываются в `bin/tray-sing-box.log` для отладки
- **Автозапуск**: использует Планировщик задач Windows (Task Scheduler) для запуска с правами администратора
  - Задача создается с именем "SingBoxTray" через XML-конфигурацию
  - Запускается при входе пользователя с наивысшими привилегиями
  - Приложение автоматически ждет готовности системного трея (до 60 секунд)

## Решение проблем

### Приложение не запускается
- Убедитесь, что вы запускаете приложение с правами администратора
- Проверьте, что sing-box.exe находится в той же папке

### VPN не включается
- Убедитесь, что файл config.json существует и корректен
- Проверьте логи sing-box

### Автозапуск не работает (иконка в трее не появляется)
- **Проверьте лог-файл**: `bin/tray-sing-box.log` - там записываются все события запуска и ошибки
  - Должна быть запись "Waiting for Windows Explorer to be ready..."
  - Затем "Explorer.exe is running"
  - Затем "Application started"
- Откройте Планировщик задач Windows (`Win+R` → `taskschd.msc`)
- Проверьте наличие задачи "SingBoxTray"
- Убедитесь, что задача настроена на запуск при входе пользователя
- Проверьте, что путь к приложению в задаче корректен
- Попробуйте запустить задачу вручную: ПКМ на задаче → "Выполнить"
- После перезагрузки приложение автоматически ждет готовности системного трея (это может занять несколько секунд)
