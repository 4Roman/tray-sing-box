# Описание работы приложения
Программа должна запускать vpn клиент с помощью ядра sing-box. Оно будет располагаться рядом с бинарником sing-box.exe и конфигом для запуска config.json.
Сейчас я запускаю vpn такой командой ```sing-box.exe run -c config.json```. Сам интерфейс программы следующий - трей с тремя пунктами:
1. Красный/зеленый шарик в зависимости от текущего статуса ядра sing-box.
2. Включить/выключить (в зависимости от текущего состояния).
3. Автозапуск (тут должна показываться или не показываться галочка в зависимости от текущего состояния)

## Требования
1. Стек - Golang.
2. Результат билда должен быть exe файл.
3. Операционная система только Windows.
4. При запуске требовать права администратора, автозапуск тоже должен быть с правами администратора.
